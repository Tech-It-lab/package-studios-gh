# 📦 Package Studios

Welcome to the official repository for **Package Studios** — a creative media agency specializing in video production, branding, content creation, and storytelling for modern brands.

## 🔗 Website
[https://packagestudios.com](https://packagestudios.com)

## 🖥️ About the Project

This is the frontend source code for the Package Studios website. The site showcases our portfolio, services, and booking capabilities. Built with a modern tech stack, it delivers fast performance, responsive design, and seamless video playback.

## ✨ Features

- 🎥 Full-screen hero video background
- 🖼️ Portfolio gallery with interactive media
- 🧠 Smart content layouts for services and team
- 📅 Booking form with calendar and service selection
- 🌐 Responsive design (mobile, tablet, desktop)
- ⚡ Deployed on [Netlify](https://www.netlify.com/)

## 🛠 Tech Stack

- **Framework:** React + TypeScript
- **Bundler:** Vite
- **Styling:** Tailwind CSS
- **Forms & State:** React Hooks
- **Media:** MP4 + Image assets in `public/`
- **Hosting:** Netlify
